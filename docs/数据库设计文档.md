# 新加坡红酒项目（智能分酒模式）数据库设计文档

> 版本: V1.0 | 日期: 2026-09-25 | 数据库: MySQL 8.0+ | 字符集: utf8mb4

---

## 1. 设计概述

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| 双单解耦 | 交易主订单(Order)与硬件履约单(DispenseTicket)独立状态机，物理隔离资金域与机械域 |
| 多租户隔离 | 所有业务表携带 bar_id/supplier_id 租户字段，查询层强制拦截 |
| 原子容量控制 | 瓶位在机余量使用 `UPDATE...WHERE current_capacity >= volume` 原子扣减防超卖 |
| 软删除 | 全表采用 `deleted` 逻辑删除字段，配合 MyBatis-Plus 自动过滤 |
| 审计字段 | 全表统一 create_time/update_time/create_by/update_by 审计追踪 |

### 1.2 ER 关系总览

```
sys_user ──┬── order_main ──── dispense_ticket
           │       │                  │
           │       │                  │
     bar ──┤   bar_wine_menu      dispenser_slot
           │       │                  │
           │   wine_sku          dispenser
           │
           ├── reconcile_log
           └── loss_audit_log
```

## 3. 状态机定义

### 3.1 交易主订单状态机（OrderStatusEnum）

```
PENDING(1,待支付) ──支付发起──→ PAYING(2,支付中) ──回调成功──→ PAID(3,已付款/待履约)
       │                              │                              │
       │                              │                        ┌─────┴─────┐
       │                         回调失败                   出酒成功    出酒失败/取消
       │                         ↓回退                      ↓           ↓
       └──────────────────── PENDING(1)            COMPLETED(4)  REFUNDED(5)
```

### 3.2 硬件履约单状态机（DispenseTicketStatusEnum）

```
READY(1,就绪待出) ──确认出酒──→ DISPENSING(2,出酒中) ──┬─成功──→ SUCCESS(3,已出酒)
                                                       └─失败──→ FAILED(4,出酒失败)
```

### 3.3 支付状态（PayStatusEnum）

| 代码 | 状态 |
|------|------|
| 0 | 未支付 |
| 1 | 成功 |
| 2 | 失败 |
| 3 | 已退款 |

## 4. 并发控制策略

### 4.1 原子容量扣减

```sql
-- 下单时预占容量（防超卖）
UPDATE dispenser_slot 
SET current_capacity = current_capacity - #{volumeMl}
WHERE dispenser_id = #{dispenserId} AND slot_no = #{slotNo}
  AND current_capacity >= #{volumeMl} AND deleted = 0

-- 退款/取消时返还容量（不超过初始容量）
UPDATE dispenser_slot 
SET current_capacity = LEAST(initial_capacity, current_capacity + #{volumeMl})
WHERE dispenser_id = #{dispenserId} AND slot_no = #{slotNo} AND deleted = 0
```

### 4.2 Redis 分布式锁

| 锁 | Key 格式 | TTL | 用途 |
|----|----------|-----|------|
| 瓶位锁 | `wine:lock:slot:{dispenserId}:{slotNo}` | 15s | 下单/出酒串行化 |
| 幂等锁 | `idem:{idempotencyKey}` | 30s | 防重复下单 |
| 幂等缓存 | `wine:idem:order:{idempotencyKey}` | 24h | 幂等结果缓存 |
